# PS4 Download Monitor 7.0.0 (official release: no custom theme engine, lightweight)

You asked to remove everything related to the themes feature and keep the app light. What this build is:

- **A full revert to your original v6.5 project** (re-extracted from the zip you first sent), not a hand-edited strip-down of v6.15. This removes, completely, everything I added across the "Design DNA" work: `ArtAnalyzer.kt`, `DnaGenerator.kt`, `DnaCore.kt`, `DnaKit.kt`, `DnaJson.kt`, `GameTraits.kt`, the genre-detection code, the per-game-type visual profiles (Ghost of Tsushima, Hollow Knight, Tekken, Elden Ring/soulslike, mythic, sports, etc.), the decoration-level and text-size settings, the four bundled fonts and their licence files, and the "Theme for this game" picker — all of it, by construction, since none of it exists in v6.5.
- **What I kept, on top of that pristine base** (two small, independent things, not "theme" features):
  1. The trophy-reading speed fix: `TrophyLib.accountDb` was listing a PS4 folder it didn't need on every single call; that extra network round trip (per account, per game) is now only made when something actually fails. Same fix as before, re-applied to the original file.
  2. "About the game" in a game's Details tab (genre, age rating, release date, developer, publisher, a short spoiler-filtered premise) — new, small, self-contained files (`GameFacts.kt`, `GameAboutUi.kt`), using only the game's name, cached on the phone, with its own plain on/off switch in Settings ("Look up game information online"). It doesn't touch colours, shapes, or fonts, so I read it as informational, not "a theme" — but if you want it gone too, say so and I'll remove it, it's fully separable.
- **What I deliberately left alone:** your original app, as uploaded, already had its own small "Settings > Theme" screen (colour presets, a custom colour picker, and per-game accent colour from the cover) — that's in v6.5 itself, predates anything I built, and several other screens (download cards, notifications) read their colours through it (`LocalTokens`). I did not touch it: it's not something I added, and I have no way to build or test this app here, so I'm not willing to gut foundational colour plumbing I didn't write on a guess. If you want that original colour-preset screen gone as well, tell me and I'll do that as its own careful pass rather than mixed into this one.
- Not verified: I have no Android SDK or device here, so this was not built or run. Please build it on your end (GitHub Actions, as usual) and tell me if anything fails to compile.
